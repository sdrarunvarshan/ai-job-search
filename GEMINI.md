# Gemini / Antigravity Quickstart

This repository shares one workflow with Claude Code, OpenCode, and Codex. Do not copy command logic into this file.

1. Install [Bun](https://bun.sh). Optional: LaTeX or Typst for local PDFs; optional `pip install pypdf` for the ATS check.
2. Run the `setup` command from `.claude/commands/` to populate the candidate profile.
3. Run `scrape` from `.claude/commands/` to search installed portals.
4. Run `apply` from `.claude/commands/` with a job URL or pasted posting.

Profile data lives in `CLAUDE.md` and `.claude/skills/job-application-assistant/`.
